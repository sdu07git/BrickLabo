Historique v0.1.0
BrickLabo by SDU7 — version 0.1.0

INSTALLATION DU CORRECTIF
Fermez le logiciel. Extrayez tout le ZIP du correctif, lancez
APPLIQUER_CORRECTIF.bat et choisissez le dossier du logiciel existant.
Ensuite lancez BrickLabo.exe ou DEMARRER.bat.
Les données et réglages existants sont conservés. Une sauvegarde des
fichiers modifiés est créée dans le dossier du logiciel.

NOUVEAUTÉS
- Nouveau nom et version affichés dans la fenêtre principale.
- Sans API BrickLink : palette de rendu 3D provenant des couleurs
  Rebrickable importées, et choix libre d'une couleur.
- Import facultatif de Colors.txt BrickLink via Mise à jour des données.
  La palette et la disponibilité d'une couleur pour une pièce sont distinctes.
  Les catalogues TXT fournis ne contiennent pas la disponibilité des couleurs.
  Les identifiants BrickLink et Rebrickable ne sont pas interchangeables.
- Retirer un set du stock demande si ses pièces doivent aussi être retirées.
  Oui soustrait les quantités ajoutées ; Non conserve les pièces ; Annuler
  laisse le stock intact. Les pièces et mini-figs sont concernées.
- Aperçu 3D / photo dans les tableaux de composition ; changement du visuel
  limité à la sélection ; chargement des photos BrickLink GIF et autres formats.

VALIDATION
Tests Python et interface Qt exécutés sous Linux en mode hors écran.
Le lanceur et l'installateur Windows nécessitent une vérification sur Windows.
Les téléchargements réels de photos BrickLink ne sont pas vérifiés ici.
