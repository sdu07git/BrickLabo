Ressources fournies avec les sources BrickLabo : catalogues Rebrickable et BrickLink, correspondances de références et couleurs, catalogue BrickArchitect, supplément de modèles et fichiers de langue.

`complete.zip` est l'archive LDraw principale. Elle est exclue du dépôt GitHub en raison de sa taille. La reprendre depuis le ZIP source/complet v0.1.39 téléchargé pour conserver les modèles de cette livraison. Une [archive officielle LDraw](https://library.ldraw.org/library/updates/complete.zip) peut également être enregistrée ici sous ce nom ; son contenu dépend de sa version.

Origines et droits : [Sources et licences](../documentation/SOURCES_ET_LICENCES.html). Les fichiers de licence sont conservés dans [licences](../licences).

The supplied resources include catalogues, reference and colour mappings, BrickArchitect data and supplementary models, and language files. The main LDraw `complete.zip` archive is not tracked in GitHub because of its size. Copy it from the downloaded v0.1.39 source/complete package to reproduce the shipped models, or use an official LDraw archive.
