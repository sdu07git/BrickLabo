# Ressources BrickLabo v0.1.54

Le catalogue BrickArchitect se trouve dans `brickarchitect.json` et son supplément LDraw dans `brickarchitect_ldraw.zip`. Les couleurs, correspondances et traductions livrées restent dans ce dossier.

L’archive LDraw `complete.zip`, bibliothèque officielle UPDATE 2026-09, est incluse dans les ZIP Windows et Sources de cette version. Elle dépasse la limite des fichiers du dépôt GitHub ; pour développer depuis Git, reprendre l’archive du ZIP Sources ou télécharger la [bibliothèque officielle LDraw](https://library.ldraw.org/library/updates/complete.zip) et la placer ici. Les bases Rebrickable et BrickLink sont importées dans le logiciel par l’utilisateur. Le bouton de mise à jour LDraw conserve les fichiers externes et l’archive livrée avec le logiciel ; la bibliothèque active est indiquée dans la base locale.

Origines et droits : [SOURCES_ET_LICENCES.html](../documentation/SOURCES_ET_LICENCES.html). Empreinte et origine de la bibliothèque officielle : `licences/LDraw/BIBLIOTHEQUE_OFFICIELLE.json`.

`button_help.json` contient les explications courtes des boutons en francais et anglais, avec les contextes particuliers.

Téléchargements de la [release v0.1.54](https://github.com/sdu07git/BrickLabo/releases/tag/v0.1.54) : les ZIP Windows et Sources contiennent la bibliothèque officielle complete.zip.
