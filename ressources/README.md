# Ressources BrickLabo

Les catalogues et autres ressources livrés sont conservés dans ce dossier.

`complete.zip` (bibliothèque LDraw) dépasse la limite de taille d’un fichier GitHub et reste exclu de Git. Il est inclus dans **BrickLabo_v0.1.43_Sources.zip** et **BrickLabo_v0.1.43_Complet.zip**, disponibles dans les [releases](https://github.com/sdu07git/BrickLabo/releases). Copier ce fichier ici pour retrouver les modèles de la version livrée. Les archives automatiques « Source code » de GitHub ne l’incluent pas.

Les origines et licences sont décrites dans [SOURCES_ET_LICENCES.html](../documentation/SOURCES_ET_LICENCES.html).

## English

The shipped catalogues and other resources are retained in this folder. The LDraw `complete.zip` exceeds GitHub’s file size limit and is excluded from Git. It is included in **BrickLabo_v0.1.43_Sources.zip** and **BrickLabo_v0.1.43_Complet.zip** from the releases above. Copy it here to restore the shipped models; automatic GitHub “Source code” archives omit it.
