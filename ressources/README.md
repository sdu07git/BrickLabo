# Ressources BrickLabo v0.1.45

Les catalogues et autres ressources livrées sont conservés dans ce dossier. Catalogue BrickArchitect : `brickarchitect.json` ; supplément : `brickarchitect_ldraw.zip`. Origines et droits : [SOURCES_ET_LICENCES.html](../documentation/SOURCES_ET_LICENCES.html).

`complete.zip` (LDraw) dépasse la limite de taille de GitHub et reste exclu de Git. Il est inclus dans **BrickLabo_v0.1.45_Sources.zip** et **BrickLabo_v0.1.45_Complet.zip**, disponibles dans la [release v0.1.45](https://github.com/sdu07git/BrickLabo/releases/tag/v0.1.45). Copier cette archive ici pour retrouver les modèles livrés. Les archives automatiques « Source code » de GitHub ne l’incluent pas.

## English

The shipped catalogues and other resources are retained in this folder. The LDraw `complete.zip` exceeds GitHub’s regular file-size limit and is excluded from Git. It is included in **BrickLabo_v0.1.45_Sources.zip** and **BrickLabo_v0.1.45_Complet.zip** from the release above. Copy it here to restore the bundled models; automatic GitHub “Source code” archives omit it.
