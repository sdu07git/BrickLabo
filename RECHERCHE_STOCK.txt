BrickLabo v0.1.35 — Stock utilisable et constructions alternatives

Depuis Mon stock, ouvrir « Sets réalisables avec Mon stock ».
1. « Choisir le stock utilisable… » : décocher les sets à garder montés et/ou
   les lignes de pièces à réserver. Filtrer les lignes par nom, référence, source
   ou type. Les boutons tout cocher/décocher agissent sur les lignes visibles.
2. Rechercher les sets réalisables avec ce stock filtré, ou cliquer sur
   « MOC avec les pièces disponibles… », puis « Rechercher ».

Les pièces en vrac fonctionnent aussi sans aucun set possédé. Un set décoché
réserve ses quantités enregistrées dans le suivi d’ajout au stock, sans soustraire
une deuxième fois une ligne de pièces elle-même décochée. Les quantités restantes
restent utilisables. Si un ancien set n’a aucun suivi, la recherche signale qu’il
ne peut pas être exclu automatiquement : sélectionner ses pièces manuellement.
Les exclusions ne suppriment rien du stock. Elles concernent les recherches,
pas l’export global du stock. Les détails et CSV du résultat utilisent le même
stock filtré que le calcul initial.

Recherche de MOC : la clé API Rebrickable est nécessaire. Le logiciel recherche
les sets Rebrickable dont toutes les pièces sont disponibles en couleurs exactes,
puis leurs constructions alternatives, par lots de 20 sets. Continuer avec
« Analyser les 20 sets suivants ». Arrêter reste possible ; les résultats déjà
obtenus restent affichés. Les réponses complètes sont mises en cache 24 heures.
Les MOC identiques sont regroupés avec la liste de leurs sets de départ.
La sélection montre la photo ; le double-clic ouvre la construction et ses notices.

Limite de l’API v3 : aucune recherche exhaustive de MOC par stock, ni inventaire
général des MOC. Ces résultats sont donc des suggestions obtenues via les sets
reconstituables. Vérifier l’inventaire du MOC et les éventuelles pièces de rechange
sur le site. Certaines notices sont payantes. Chaque proposition est indépendante :
le logiciel ne garantit pas de pouvoir construire tous les résultats à la fois.
Documentation : https://rebrickable.com/api/v3/docs/

Clic droit sur un set des résultats : « Voir les constructions alternatives ».
Cette action existait déjà sur les sets de Mon stock et des catalogues.

Installation : fermer BrickLabo, extraire l’archive complète dans un dossier neuf,
puis copier le dossier Donnees de l’ancienne version pour conserver son stock,
ses clés et ses réglages. Conserver une sauvegarde de l’ancienne version.
